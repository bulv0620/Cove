# SMB 个人文件

Files 位于基础设施导航，路由为 `/files`。Server 使用 SMB 连接 NAS；浏览器不接触 SMB 凭据。当前支持个人 home 目录浏览、当前目录筛选/排序、列表/图标视图、新建文件夹、多文件上传队列、单文件下载、同目录重命名，以及文件与空文件夹删除。

Files 不显示额外页面标题区，文件管理器使用 flex 填满顶部栏以下的 main 区域。页面本身不滚动，文件列表在内部滚动。目录树不常驻占用浏览宽度，通过刷新按钮右侧的图标按钮打开尺寸受限、内部可滚动的浮层。传输任务通过搜索框右侧具有可访问名称的图标按钮打开弹窗，不在文件管理器下方插入内容区。

## 身份与绑定

- NAS 主机、共享、domain 和安全策略由 Server env 统一设置。每个 Cove 用户独立绑定 NAS 用户名和密码，密码采用独立主密钥的 AES-256-GCM 加密保存在数据库。
- 用户管理操作列中的独立“SMB 账号”按钮和弹窗需要 `identity.user.page` 和 `identity.user.bind_smb`，并与普通用户编辑弹窗分离。弹窗支持测试、保存、更新和解绑；测试成功/失败使用文字、图标及语义颜色反馈，输入变化会清除旧测试结果。读取接口不返回密码或密文。更新前重新验证认证及根目录可读；验证失败保留旧绑定。
- Files 需要 `infra.files.page`；上传、下载、新建目录、重命名和删除分别需要 `infra.files.upload`、`infra.files.download`、`infra.files.mkdir`、`infra.files.rename`、`infra.files.delete`。NAS ACL 仍独立生效。
- 平台超级管理员也需要绑定 SMB 身份。内置 administrator 角色延续既有“所有当前和未来权限”行为，自定义角色需要显式授权。
- 文件请求从当前会话派生用户，不接受客户端指定其他用户、NAS 主机或共享。两个 Cove 用户若绑定同一 NAS 账号会共享该账号的文件视图。
- 威联通的 `home` 按 SMB 身份映射个人虚拟空间，不能用 `homes/本地用户名` 替代身份隔离。
- 解绑、换绑、用户禁用/删除和权限变更触发连接复查或撤销；长传输每 2 秒复查身份/版本。已经发送的字节或已成功提交的 NAS 文件无法撤销。删除平台用户不删除 NAS 账号或个人文件。
- Cove 改密不修改 NAS 密码。NAS 改密后需更新 SMB 绑定。修改 NAS 目标配置会使旧绑定要求重新验证，不向新目标自动发送旧密码。

## 浏览与传输

- 根目录显示“我的文件”；目录树从顶部工具栏按需打开和展开，选择目录、按 Esc 或点击外部后关闭。支持面包屑、前进/后退、上一级、刷新、详情、当前目录筛选、名称/时间/大小/类型排序。默认目录优先、名称升序；不递归统计文件夹大小。
- 文件列表依据文件名扩展名，以图标形状和主题兼容颜色区分文档、PDF、表格、演示、图片、视频、音频、压缩包和代码；匹配不区分大小写，未知类型显示通用文件图标。该展示不读取文件内容，也不作为安全或 MIME 类型判断依据。
- 文件列表分页并虚拟化；目录快照按用户、绑定版本及筛选条件隔离，30 秒过期。单次枚举默认最多 50,000 项，超过上限明确报错，不把部分数据当成完整搜索结果。元数据快照全局最多 64 MiB，单快照最多 32 MiB。
- 列表和图标视图均支持多选：普通点击恢复为单选，Ctrl/Cmd 点击切换单项，Shift 点击连续范围；每项也有至少 44px 的显式选择按钮，触屏无需组合键。方向键恢复为当前项单选，Shift + 方向键扩大范围，Ctrl/Cmd + A 选择当前已加载条目，Esc 或点击浏览区空白处清空选择。状态栏、选中背景、勾选图标和 `aria-selected` 使用同一选择状态。
- 默认隐藏隐藏文件，可手动显示；应用保留的 `.cove-upload-*.part` 不作为普通文件列出。拒绝路径穿越、UNC/盘符、备用数据流、控制字符、reparse point 和 DFS 共享。NAS 自身必须限制共享之外的符号链接与 ACL。
- 选择或拖入多个文件上传至当时指定的目录。应用内导航时队列保留；刷新/关闭浏览器会中断。上传进度表示浏览器已发送字节，完成状态要等待 NAS 提交确认。
- 上传先独占创建同目录临时文件，再通过同句柄原子“不覆盖 rename”提交。冲突时改名或跳过；不支持覆盖、跨目录移动、目录上传、打包下载或续传。多选时不会启用下载；单文件下载只在恰好选中一个受支持文件时可用。
- 单选受支持的文件或文件夹可以重命名。客户端只提交新名称，Server 固定原父目录并使用 SMB 不覆盖 rename；同名冲突、链接、临时文件、非法名称和越界路径均拒绝。工具栏、右键菜单和 F2 提供入口。
- 一个或多个受支持对象可以在确认弹窗后删除。Server 逐项删除文件或空文件夹，根目录和非空文件夹不可删除，不递归清空目录；批量操作可能部分成功，响应返回成功路径与逐项安全错误码，界面保留失败项、刷新实际目录并显示失败数量。工具栏、右键菜单和 Delete 键提供入口。Cove 不提供撤销，NAS 是否进入回收站取决于 NAS 自身策略。
- 默认单文件 10 GiB、每用户 2 个活跃传输、全局最多 8 个 SMB 进程、每用户最多 100 个未结束上传；可通过 env 调整。读取和绑定测试也受全局 SMB 进程数约束。
- 下载使用 JWT 创建短期票据，随后由原生浏览器请求通过 HttpOnly、SameSite=Strict、路径受限 cookie 获取文件。票据随机 secret 不在 URL 中，服务端只保存哈希；60 秒有效、一次性消费，消费前重新校验用户与绑定。下载为附件，不预览 HTML/SVG，不支持 Range/续传。
- 文件流有背压，不在 Server/Web 内存或磁盘保存第二份完整文件。上传/下载完成审计表示 Server 完成传输，不保证浏览器已将内容落盘。

## 中断与维护

- 上传操作持久化到 MySQL。过期 RUNNING 租约转为 INTERRUPTED，过期 COMMITTING 转为 RECONCILING；当前实例的活跃任务不被恢复扫描改写。
- 未知提交结果只有 NAS 对象标识与长度均一致才确认为成功。不得仅凭同名文件存在就宣称成功，也不自动覆盖或重传。
- 失败/取消/中断的临时对象在 24 小时后按操作登记和对象标识清理，不按名字前缀批量删除未知对象。绑定被删除或替换后无法使用旧凭据清理，会保留待处理记录；维护者需在 NAS 上核对这些临时文件。
- 完成且无需清理的操作记录保留 7 天。NAS 离线与认证失败分别提示，网络故障不会删除绑定，NAS 凭据错误也不会让浏览器退出 Cove 登录。
- 日志、审计、构建与响应不得含密码、加密密文、完整 token 或原始 SMB 响应；操作审计使用用户/操作 ID、状态码等摘要。
