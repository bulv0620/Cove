# 页面会话标签

Cove 已登录工作台在顶部栏与主内容区之间显示页面会话标签。它用于同时保留多个顶级功能的页面现场；左侧导航和浏览器 URL 仍是可访问位置的入口，Server 权限校验仍是授权边界。

## 打开与切换

- 每个当前可访问的顶级路由最多对应一个页面会话。左侧导航、直接 URL、页面内链接或浏览器前进/后退进入路由时，会创建或激活同一路由已有的标签，不产生重复实例。
- 左侧导航重新激活已打开的页面会话时，会恢复该会话保存的完整 `pathname + search + hash`。例如 Files 会回到原来的 `?path=...` 目录；如果会话尚未打开，则从侧栏配置的基础路径创建。
- 直接 URL、页面内链接和浏览器前进/后退以本次请求的地址为准，可以覆盖会话先前保存的位置，不会被侧栏恢复规则改写。
- Dashboard `/` 是每个工作台运行周期的默认会话。直接进入其他合法路由时会同时创建 Dashboard 和目标会话，并激活目标。
- 切换标签不会卸载页面组件，因此搜索、筛选、排序、选择、页内路径、滚动位置、未提交输入及弹窗开关等本地页面状态会保留。
- 页面会话保活不冻结服务端数据。React Query 仍按显式刷新、mutation 失效和页面既有策略更新数据；已不存在的对象不能因为页面状态保留而继续被视为有效。

## 关闭与回退

- 所有页面会话（包括 Dashboard）都可以关闭。关闭会卸载页面组件并丢弃该实例的本地状态；之后重新进入同一路由会创建全新页面实例。
- 关闭非活动会话不改变当前 URL。关闭活动会话时，系统使用 `replace` 激活最近使用的剩余会话。
- Dashboard 关闭后，只要仍有其他会话就保持关闭。关闭最后一个会话时，系统立即创建并激活全新的 Dashboard，将 URL 替换为 `/`，不会显示空标签栏或空内容区。
- 关闭页面不会撤销已经提交给 Server 的操作，也不会取消位于全局 TransferProvider 中的文件传输。重新打开页面时以 Server 和全局任务状态为准。

## URL、刷新与认证边界

- 活动标签、地址栏、顶部面包屑和侧栏高亮保持同步。浏览器历史进入已关闭路由时会创建新的页面会话；未知路径仍显示 Not Found，无权限路径仍由权限路由拒绝。
- 页面会话只存在于当前浏览器内存，不写入 localStorage/sessionStorage。硬刷新、关闭浏览器页面或重新加载应用会释放全部组件状态；身份恢复后根据当前 URL 创建新的 Dashboard 与目标会话。
- 退出、API 401、强制改密或认证用户 ID 改变时，全部页面会话和上一用户的私有 Query 缓存被清除。权限集合收缩时，不再可访问的会话立即卸载；活动页失权则回退到最近使用的合法会话或 Dashboard。

## 交互与布局

- 桌面侧栏可以折叠为保留图标与可访问名称的窄栏，主内容偏移同步调整；折叠偏好保存在当前浏览器。移动端继续使用完整导航抽屉，不读取该偏好改变抽屉内容。
- 标签栏保持单行，空间不足时可以通过左右按钮、触控板或触摸横向滚动，活动标签会进入可见区域。
- 标签栏使用 `tablist`/`tab`/`tabpanel` 语义。键盘支持左右方向键、Home/End、Enter/Space 和 Delete；活动状态同时通过文字强调和底部指示表达。
- 后台页面保留挂载但从布局、焦点顺序和辅助技术树中隐藏。页面内 Modal 在后台时不显示、不锁定 body、不捕获键盘；返回页面后可按保留状态恢复。
- 标签栏使用项目现有语义颜色、Lucide 图标和中英文翻译，并适配深浅主题。Files 的可用高度同时扣除顶部栏和标签栏，内部列表与状态栏不会被遮挡。
