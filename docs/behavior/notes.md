# SMB 笔记（Notes）

Notes 位于 Workspace 导航，路由为 `/notes`。它复用当前用户的 SMB 绑定，把笔记以普通 `.md` 文件保存在 home 下固定目录 `Markdown Notes/`；MySQL 只保存可恢复的写入操作状态与脱敏审计，不保存笔记正文。NAS 文件系统始终是正文的事实源，任何外部 SMB/文件管理器的修改都被视为合法变更。

## 权限与目录

- 页面与新建、保存、重命名、删除分别需要 `workspace.notes.page`、`workspace.notes.create`、`workspace.notes.update`、`workspace.notes.rename`、`workspace.notes.delete`；NAS ACL 仍独立生效，超级管理员也必须绑定自己的 SMB 身份。
- 目录树仅包含文件夹与 `.md` 文件；其他类型（含链接与 reparse point）被忽略或拒绝。名称与路径校验以 Server 为准：保留名 `.cove-note-` 前缀、控制字符、越界长度都会被拒绝。
- 正文必须为合法 UTF-8（剥离 BOM），默认上限 5 MiB；目录列表只枚举元数据，从不读取正文。
- `Markdown Notes/` 根目录在首次访问时校验并创建；为避免每次操作重复付出一次 SMB 会话，校验结果在 30 秒窗口内复用——窗口内被外部删除的根目录会在下一个动作重新创建（错误码与冲突判定不变）。

## 页面行为

- 状态加载使用与 Files/图床一致的整区占位：SMB 未启用、未绑定、绑定配置失效或 NAS 不可达时显示原因、帮助文案、刷新和管理入口；可用后进入与 Files 一致的全高布局——左侧目录树、右侧编辑器，页面本身没有标题与描述，也不使用卡片包裹；移动端在目录树与编辑器之间单栏切换。
- 左侧目录树按层懒加载：展开某个目录时才请求该层，根目录默认展开；打开一篇深层笔记会自动展开其所在路径。目录行点击展开/收起，笔记行点击打开该笔记。
- 目录树区域在宽屏上可折叠、可调宽：拖动分隔条调整宽度（双击恢复默认 280px，聚焦后用左右方向键按 16px 步进），宽度限制在 200–520px。收起后目录树区域整体让给编辑器，不留窄栏；收起/展开是编辑器面板左上角**同一个按钮**在原地切换（图标与 aria-label 随之变化，没有打开笔记时同一按钮出现在空状态的左上角同一位置）。宽度与折叠状态按用户保存在浏览器本地（`cove.notes.tree.<userId>`），与其它页面偏好一致；手机上目录树仍是整屏/整宽的切换，不受这两个偏好影响。
- 树没有顶部工具栏：新建、重命名、删除、刷新全部收在行右键菜单里（键盘的 ContextMenu 键同样可用，菜单会锚定到该行）。目录行提供新建笔记、新建文件夹、重命名、删除、刷新，笔记行提供重命名、删除；根行只提供新建与刷新。菜单项按用户权限出现，无任何可用操作时不弹空菜单。行的操作对象就是被右键的那一行，因此不存在「先选目录再点工具栏」的隐藏状态；新建对话框会显示目标目录。
- 刷新只作用于被右键的那一个目录节点（按查询键精确失效），其他层级保留已加载的列表；从外部 SMB 客户端改动过的目录因此可以单独重新读取，不需要刷新整棵树。
- 当前笔记由 `?note=` 查询参数表达，与页面会话的挂载、恢复、关闭语义一致；树的展开状态是本地 UI 状态。关闭笔记页面会清理其查询缓存，重新进入为全新状态。
- 编辑区域只有两种状态：已打开笔记（含加载中与读取失败）和未打开笔记的空占位。空占位描述的是「没有打开的笔记」，与左侧目录树的「此文件夹为空」提示互不复用——文件夹里有笔记但未打开时不会显示文件夹为空的文案。
- 页面不轮询 SMB：目录与状态只在进入页面、手动刷新或保存成功等事件后刷新，全局 `refetchOnWindowFocus` 关闭。

## 编辑器与方言

- 所见即所得编辑器为 MDXEditor（MIT，版本锁定），方言限定为：段落、一至六级标题、粗体、斜体、删除线、链接、引用、有序/无序列表、任务列表、水平线、围栏代码块与 GFM 表格。工具栏只暴露方言内格式（不提供下划线、上下标等会生成 HTML 的按钮）。
- 围栏代码块在语言属于批准清单（js/ts/tsx/jsx/vue/json/html/css/python/go/rust/java/sql/bash/shell/yaml/markdown 及常见别名）或未标注语言时，用内置 CodeMirror 编辑器编辑：语法高亮、行号，获得焦点时工具栏变成该围栏的语言下拉；语法包按语言从 CodeMirror 的 language-data 动态加载，只有打开对应围栏时才下载。清单之外的语言继续用纯文本编辑器，保证任何围栏都能编辑（不会因缺语法包变成只读）。深色主题下代码块与编辑器自带部件的浅色硬编码由笔记样式表统一覆盖：CodeMirror 的编辑器表面、行号条与当前行高亮，以及 MDXEditor 硬编码为白色的 `--basePageBg`（语言下拉、浮动面板与对话框的背景，弹层容器同样带编辑器类名所以覆盖得到）。
- 导入时的规范化（如 `-` 列表标记统一为 `*`、`---` 统一为 `***`、表格留白对齐）在第一次保存前被视为等价，不计为用户修改；同一段内容首次规范化后保持稳定。
- 原始 HTML 在编辑器中保持惰性并原样导出，不渲染、不执行；JSX 与未知语法会使导入中止，该笔记自动切换为只读源码视图（保留原文、不执行、不允许保存半成品），从根源上避免静默覆盖。
- 编辑器占满编辑区高度（MDXEditor full-height 链条从容器到 contenteditable 都是确定高度的 flex 链）：点击正文下方空白区域同样进入编辑并把光标放到末尾，不必精确点到某一行；滚动由编辑器自身的滚动容器负责。
- 从 Typora 等富文本来源粘贴时，代码块会在导入前被规范化：这类剪贴板 HTML 用标记而不是换行符分隔代码行（Typora 的围栏是行内 `<span>` + `<br>`，其他编辑器是每行一个块级元素），行间没有换行文本，直接读取会把整块代码拼成一行。规范化按「显式 `<br>` 必结束当前行、块级边界仅在行内有内容时结束行、行内空格与缩进保留、块内空行保留（`<br><br>`）、不换行空格还原为普通空格」重建文本，丢弃随代码复制的编辑器装饰（行号、隐藏测量样本、语言提示），并尽量保留语言标记；文本已经能往返的代码块、以及段落/列表等普通 HTML 原样传回。
- 修正后的剪贴板负载通过重发一个等价 paste 事件交给编辑器（系统剪贴板负载在 paste 期间只读，无法就地改写），因此图片粘贴等其它 paste 能力不受影响。
- 规范化同时清掉源编辑器留在代码里的不可见占位字符（零宽空格、不换行空格、软连字符、CR、BOM 等——正是 CodeMirror 会画成"控制字符小方块"的那一组），只保留 Tab 与换行；仅含占位字符的行按空行保留。注意该清理只作用于代码块，段落中的同类字符不会被改动，也不会改写已经保存过的旧笔记。
- 键盘、撤销/重做、中文输入法由编辑器内核处理；界面文案跟随中英文与深浅主题。

## 保存、冲突与恢复草稿

- 每篇打开的笔记持有一个不透明 revision 令牌；保存使用条件替换交换：Server 经 SMB worker 以只读共享钉住目标并校验对象身份，写入同目录登记的临时文件，提交前重新校验，然后把钉住的原文件改名为登记备份、以不覆盖改名让新内容占用正式路径、身份确认后释放备份。任何不匹配返回 `NOTE_CHANGED` 且零写入；外部改动永远不会被静默覆盖。
- 保存成功后正式路径上是新的 SMB 对象，因此保存响应会带上提交后的对象身份，客户端据此更新本地列表项；重命名与删除校验的对象身份由此始终新鲜，不会出现「刚保存就重命名被判为外部修改」。
- 保存完全由用户触发：输入只把笔记标记为「有未保存的修改」，编辑器右上角的保存按钮与 `Ctrl/Cmd + S` 才会写入 NAS；同一内容不重复写入，进行中的保存串行化，绝不并发覆盖。
- 未保存时切换笔记会先询问：保存并切换（保存失败则留在弹窗并显示错误码）、不保存直接切换（同时删除该笔记的恢复草稿）、继续编辑。移动端返回同样经过该询问；重命名或删除当前打开的笔记会先提交未保存内容，保存失败则中止操作。
- `NOTE_CHANGED` 冻结该笔记的后续保存并给出三条出路：放弃本地草稿并重载 NAS 版本、将本地文本另存为新笔记、或继续本地编辑（仍保持 SMB 保存冻结）；其他错误（NAS 离线、磁盘满等）保留草稿并可重试。
- 恢复草稿按 用户/绑定版本/路径 存于浏览器 IndexedDB，并同时保存其来源 revision，仅在页面卸载、刷新或页面隐藏时作为兜底写入（用户显式放弃修改的笔记不写）：重新打开同一笔记且内容与 NAS 不一致时可恢复或丢弃；恢复后仍使用原 revision 做条件保存，不能借用刚读取的 NAS 新 revision 静默覆盖外部修改。旧版本遗留且没有来源 revision 的草稿只允许冻结编辑、另存副本或丢弃。保存成功即清除；登出与 401 清空全部草稿，切换账号清理他人草稿。
- 服务重启后，`NoteWriteOperation` 状态机按 SMB 对象身份、长度和 SHA-256 对账：已落盘视为成功、源仍在则中断可重试、正式路径丢失且登记备份完好时按身份恢复原文件、目标已丢失转为冲突（备份保留在 NAS 上作为最后已知内容）；未过期的活动操作不会被后台清理，过期操作只清理已登记的 `.cove-note-` 临时文件与备份，从不按前缀批量删除。

## 图片粘贴

- 粘贴或拖入 JPEG、PNG、WebP、GIF、AVIF 时调用现有图床能力并为该次上传显式请求公开；上传面板浮在编辑区右下角（不占正文版面），逐图显示进度，可取消（同时取消图床操作）、失败可重试并显示机器错误码。面板**只保留需要注意的条目**：上传成功与用户取消的条目立即消失（正文里已插入公开地址或本就未插入），只有进行中与失败的条目会留下；被拒绝的图片类型提示是瞬时反馈，数秒后自行清除，不需要用户关闭。
- 只有图床确认公开后才会把同源 `/image/{publicId}` 插入正文；`blob:`、`data:`、本地路径、SMB 路径或未确认地址一律不落正文。
- 从正文删除图片引用不会撤销或删除图床资产；图片生命周期（公开、撤销、删除）仍由图床页面管理。

## 审计与隐私

- 事件审计只含用户、动作、结果码与路径摘要（SHA-256 前 32 hex），不记录正文或路径明文；日志、响应与错误不包含 SMB 密码、密文或原始协议响应。

配置项见[Files 配置与运行](../operations/files.md)的 Notes 一节，需求与验收见[已归档的 SMB Markdown 笔记 Spec](../specs/archive/2026-09-21-smb-markdown-notes/spec.md)。
