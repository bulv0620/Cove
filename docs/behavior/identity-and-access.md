# 身份与访问行为

本文记录当前已经稳定存在的身份与访问行为。

## 登录与会话

- 用户使用本地用户名和密码登录。
- 成功登录后，客户端使用 JWT 访问受保护 API。
- 用户被禁用、密码被重置或认证版本发生变化后，旧会话应失效。
- 使用临时密码创建或重置的用户必须先修改密码，之后才能访问其他受保护页面。
- 登录失败同时按规范化用户名和可信来源 IP 计数。默认 10 分钟窗口内用户名失败 5 次或 IP 失败 20 次后进入冷却；冷却从 30 秒递增，最多 15 分钟，连续 30 分钟没有实际校验失败后重置。
- 冷却期和并发校验额度用尽时，登录统一返回 `AUTH_RATE_LIMITED`、HTTP 429 与 `Retry-After`，不查询用户或执行 Argon2id，也不透露账号是否存在或触发维度。受限请求不会延长冷却；成功登录清除用户名维度状态，不清除同一 IP 下其他账号产生的失败。
- 限流状态和短期校验额度保存在 MySQL，应用重启及共享数据库的多个 Server 使用同一额度。用户名/IP 限流键以派生 HMAC 保存，不在状态表保留原值；登录成功、实际校验失败及聚合限流进入审计。
- Server 默认忽略转发 IP 头；只有直接对端属于维护者配置的可信代理 CIDR 时，才从右向左解析代理链。IPv4 按单地址限制，IPv6 按 `/64` 聚合。

## 授权

- 权限由资源、页面权限和页面内动作权限组成。
- 角色组合一组权限，用户通过全局角色分配获得权限。
- 页面权限同时影响导航可见性和路由访问；API 仍必须单独校验权限。
- 平台超级管理员直接绕过普通权限检查，但仍受认证和强制改密规则约束。

## 管理行为

- 系统角色受到保护，普通管理操作不能随意破坏其约束。
- 重置密码生成的临时密码只展示一次。
- 删除用户会同时删除其凭据和角色绑定，属于不可恢复操作。
- 关键身份操作应进入审计日志；日志不得包含密码或完整令牌。
- 用户管理的操作列以独立“SMB 账号”按钮和弹窗维护 SMB 绑定，与普通用户编辑弹窗分离；连接测试以文字、图标和语义颜色显示结果。凭据不回显，换绑/解绑撤销旧文件连接，删除平台用户不删除 NAS 文件。详见 [Files](files.md)。

如果代码与上述规则不一致，应创建缺陷或 Spec 记录处理结论，而不是直接修改本文使其迁就偶发现状。

## Cove 浏览器状态

浏览器只使用 `cove.*` 保存登录 token、语言、主题和每用户文件视图；不迁移其他命名的状态。首次使用新名称版本需要重新登录和设置偏好。退出及 API 401 清除当前 token，存储不可用时仅在当前页面保留内存状态。
