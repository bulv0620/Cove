# 外部集成与状态

本文规定外部基础设施能力进入 Home Ops 时必须遵守的长期架构边界。原 FRP、Caddy 和 Cloudflare 统一网络控制面 Spec 已废弃；未来若重新引入相关能力，必须建立并批准新的 Spec。

## 三类状态

每个受管资源应区分：

| 状态     | 含义                            | 示例                               |
| -------- | ------------------------------- | ---------------------------------- |
| Desired  | 用户希望系统达到的状态          | 域名应指向 `immich:2283`           |
| Applied  | Home Ops 最近一次成功提交的版本 | 已生成并重载的 Caddy 配置版本      |
| Observed | 从外部系统探测到的实际状态      | DNS 已解析、FRP 在线、HTTPS 可访问 |

不得用单一 `status` 字段同时表达三者。界面显示“在线”时，应能够追溯其观测时间；超过规定时间未更新的状态必须显示为 `unknown/stale`，不能继续显示为正常。

## 协调循环

外部集成采用声明式协调：

1. API 在事务中保存期望状态与 operation 记录。
2. Worker 读取待处理 operation，并按依赖顺序调用 adapter。
3. 每一步记录开始时间、结束时间、结果和可安全展示的摘要。
4. 全部步骤成功后更新 applied revision。
5. 失败时保留上一份可用状态，记录可重试错误，不把半完成状态伪装成成功。

协调器必须具备幂等键、有限重试、退避和同一资源串行化。进程重启后应能继续未完成任务或明确将其标记为中断。

## Adapter 边界

所有外部副作用都通过接口隔离：

- DNS provider adapter：记录查询、创建、更新和删除。
- Tunnel adapter：FRP 配置生成、校验、启动、重启和健康检查。
- Reverse proxy adapter：Caddy 配置生成、校验、重载和健康检查。
- Remote host adapter：SSH 连通性测试、文件传输和受限命令执行。
- Secret provider：加密保存、读取、轮换和删除敏感值。

开发环境可以使用 deterministic fake adapter；生产环境不得以 mock 成功代替真实操作。

## 密钥边界

- 密码、API Token、私钥和 FRP authentication token 不得以明文保存在普通业务表、日志、审计 metadata 或 API 响应中。
- 业务记录只保存 secret reference 和非敏感元数据，例如 token 尾号、创建时间和最近验证时间。
- 展示层不得提供“读取已保存密码”的能力；只能替换或删除。
- 任何执行命令都必须使用参数化调用或受控脚本，不拼接未经验证的用户输入。

具体加密实现和主密钥来源必须通过 ADR 固化后再进入生产实现。

## 失败与回滚

- 配置变更必须先生成临时文件并通过目标工具校验，再原子替换生效文件。
- 重载失败时恢复上一版本，且保留失败版本供诊断。
- 跨 Cloudflare、FRP、Caddy 的操作不是数据库意义上的原子事务；使用 saga/补偿步骤表达部分成功。
- 删除公网入口时，先停止新流量，再移除下游配置；具体顺序由相关 Spec 定义。
