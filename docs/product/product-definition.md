# 产品定义

## 当前定位

Cove 是运行在 NAS 上的自托管个人工作台。当前提供身份认证、访问控制与 SMB 个人文件访问；未来功能方向见[功能规划](roadmap.md)。

当前已实现的产品能力：

- 本地用户、密码凭据和首次登录强制改密。
- JWT 会话与全局权限守卫。
- 用户、角色、资源和权限管理。
- 中英文界面、浅色/深色主题和权限驱动导航。导航仅展示已实现的概览、用户、角色、资源和文件页面，不展示规划中入口或空分组。
- 最小系统状态页与审计基础。
- Files：每用户 SMB 绑定、个人 home 浏览、新建文件夹、多文件上传、流式单文件下载、同目录重命名，以及文件与空文件夹删除。

## 当前不包含的能力

截至本文更新时，下列能力尚未实现，不能作为现有产品行为依赖：

- 图床、Markdown + Canvas 笔记、文档与音视频处理工具、定时 JS 脚本；文件覆盖、跨目录移动、递归目录删除、目录上传、分享和预览。
- 已通过完整验收的 Docker 生产部署；当前已提供单应用镜像和外部 MySQL 配置，原单镜像版本本机 clean-room 已通过；Cove 改名版本的验证见[当前 Spec](../specs/archive/2026-09-17-cove-rename/tasks.md)，实际 NAS 验证待执行。

这些能力必须通过已批准的 Spec 进入实现。

## 产品原则

- **本地优先**：核心管理面和状态存储运行在用户自己的设备上。
- **安全默认值**：密钥不进入日志、API 响应或生成的普通配置文件；危险操作必须显式确认。
- **日常易用**：围绕个人文件与日常工作提供清晰入口；只展示已实现的功能。
- **可恢复**：外部系统变更失败时保留上一份可用配置，并提供明确的失败原因和重试路径。
- **可观测**：耗时操作都必须有状态、时间和可追踪结果。
- **渐进增强**：没有配置外部集成时，现有身份和管理能力仍可独立运行。

## 目标运行环境

- 开发环境：Windows/macOS/Linux 均可运行 Web、Server 与数据库；外部集成允许使用模拟适配器。
- 生产环境：以 NAS 上的 Docker Compose 部署为目标。
- 浏览器：现代桌面浏览器为主要使用入口，小屏设备至少支持查看状态和执行常用操作。
