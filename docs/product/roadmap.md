# 功能规划

Cove 的目标是运行在 NAS 上的自托管个人工作台。下表区分已实现基础与未来方向；规划功能需另建并批准 Spec，不代表已有入口或 API。

| 模块         | 当前状态                                                                   | 规划方向                                                                     |
| ------------ | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Files        | 已有 SMB 个人文件浏览、上传、下载、新建目录、同目录重命名与文件/空目录删除 | 后续扩展另行定义                                                             |
| 图床         | 已有 SMB 图片目录、私有缩略图、手动公开链接、撤销与绑定变更失效            | 相册、批量分享、密码、期限、CDN 等另行定义                                   |
| Notes        | 未实现                                                                     | Markdown 笔记与 Canvas 画布，用于流程图等内容                                |
| Applications | 未实现                                                                     | 文档转换、音视频处理及日常小工具                                             |
| Tasks        | 未实现                                                                     | 在受限执行上下文中定期执行 JS 脚本；隔离、权限、资源配额与失败恢复待专门设计 |

身份与访问控制是这些能力的共享基础。Applications 指应用工具集合，不代表 NAS 容器管理；Tasks 不提供已实现的任意宿主机脚本执行能力。
