# 图床未绑定 SMB 空占位

## 背景与问题

图床依赖当前用户的 SMB 绑定。当前图床在状态加载和 SMB 不可用时仍显示“图床”标题、说明区，并把不可用提示放在独立卡片中；这与 Files 的整页空占位表现不一致，也让尚不能使用的页面呈现了无效的功能内容。

## 目标

- 图床在 SMB 未绑定或不可用时采用与 Files 一致的整页空占位。
- 不可用状态不显示图床标题、说明、工具栏或图片内容卡片。
- SMB 可用时保留现有图床标题、操作和图片管理界面。

## 非目标

- 不改变 SMB 绑定、权限、图片 API、上传、公开链接或删除行为。
- 不改变 Files 页面。
- 不调整 SMB 可用时的图床文案和功能布局。

## 功能需求

- `IMG-EMPTY-FR-001`：图床状态加载时必须使用主内容区居中的加载占位，不得显示图床标题和说明。
- `IMG-EMPTY-FR-002`：图床在 SMB 未启用、当前用户未绑定、绑定配置失效或状态请求失败时，必须使用占满主内容区的居中空占位，不得显示图床标题、说明、工具栏或图片内容卡片。
- `IMG-EMPTY-FR-003`：不可用空占位必须继续显示既有状态原因、配置/绑定提示、刷新操作，以及有权用户的管理入口。
- `IMG-EMPTY-FR-004`：SMB 可用时必须保留既有图床标题、操作和图片管理内容。

## 非功能需求

- `IMG-EMPTY-NFR-001`：空占位必须适配现有移动端与桌面主内容区，并兼容深浅主题和键盘操作。

## 验收条件

- `IMG-EMPTY-AC-001`：未绑定 SMB 的用户打开图床，只看到居中的不可用占位及相关操作，不看到“图床 / Image Hosting”页面标题或其说明。
- `IMG-EMPTY-AC-002`：状态加载期间不显示图床标题。
- `IMG-EMPTY-AC-003`：SMB 已绑定且有效的用户仍看到完整图床界面。
- `IMG-EMPTY-AC-004`：Web 测试、lint、typecheck、build、格式检查和差异检查通过。
