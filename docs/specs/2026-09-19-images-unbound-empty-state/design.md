# 技术设计

## 设计摘要

调整 `ImagesPage` 的早返回分支：状态加载和 SMB 不可用时不渲染图床页头，直接渲染占满图床内容区域的居中状态。SMB 可用后的页头与图片管理内容保持不变。

## 组件与边界

- 仅修改 Web 图床页面的展示结构与布局样式。
- 继续复用现有状态查询、错误映射、权限判断、刷新和用户管理入口。
- Server、共享契约、路由与页面会话机制不变。

## 数据模型与 API

无数据模型、持久状态或 API 契约变化。

## 状态与失败恢复

- `status.isPending`：显示居中加载图标。
- `!available`：显示既有不可用原因、帮助文案和操作。
- `available`：显示现有完整图床页面。

刷新仍重新请求状态；保存有效绑定后，现有查询失效机制会使图床进入可用界面。

## 安全与权限

不改变权限边界。用户管理入口仍只对超级管理员或具有 `identity.user.page` 权限的用户显示。

## 响应式与可访问性

空占位复用 Files 的弹性居中结构，在现有页面内容高度内填充；按钮保持现有可访问名称和键盘行为。深浅主题沿用语义色。

## 迁移与回滚

无需迁移。回滚页面结构即可恢复原布局。

## 待决策项

无。
