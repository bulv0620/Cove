# 技术设计

## 设计摘要

`DashboardLayout` 拥有桌面侧栏的展开状态。展开时保持 256px 宽度，折叠时使用 80px 图标栏；主内容区使用同一状态同步切换左侧偏移。侧栏内容组件接受展示模式，但不改变导航数据、权限过滤或页面会话导航 state。

## 组件与边界

- `DashboardLayout`：初始化、切换和持久化桌面折叠偏好。
- `SidebarContent`：根据 `collapsed` 隐藏视觉文字，保留可访问名称，并渲染桌面切换按钮。
- `lib/sidebar-preference.ts`：封装偏好键、容错读取和写入，复用现有 storage 边界。

## 数据模型

浏览器 localStorage 使用 `cove.sidebar.collapsed`，值仅为 `true` 或 `false`。缺失值与无效值按展开处理。

## API 契约

无 Server API 变化。

## 状态与失败恢复

切换时先更新 React 状态，再尝试写入本地存储。现有 storage helper 在存储不可用或容量不足时使用当前页面内存回退，不让异常进入 UI。

## 安全与权限

折叠不改变权限过滤、路由守卫或服务端授权。存储值不包含身份或业务数据。

## 本地开发与生产部署

无配置和部署变化。

## 迁移与兼容性

无旧键迁移；首次使用默认展开。移动端渲染既有抽屉内容且不显示桌面切换控件。

## 可观测性

纯本地展示偏好，不新增日志或遥测。

## 备选方案

仅使用进程内状态会在刷新后丢失用户选择，因此采用既有安全存储 helper。完全隐藏侧栏会降低导航可发现性，因此保留图标栏。
