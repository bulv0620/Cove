# 桌面侧栏折叠

## 背景与问题

当前 Cove 的桌面端左侧导航固定占用 256px，用户无法为主内容释放横向空间。移动端已经使用独立抽屉导航，本次只补充桌面布局能力。

## 目标

- 桌面端侧栏可以折叠为仅显示导航图标的窄栏，并可随时恢复展开。
- 折叠状态下保留路由访问、活动态、键盘焦点和可访问名称。
- 浏览器记住用户的折叠偏好；存储不可用时仍可正常操作。

## 非目标

- 不改变移动端抽屉导航。
- 不改变导航权限、路由或页面会话行为。
- 不在 Server 保存或跨浏览器同步侧栏偏好。

## 用户场景

### 收起侧栏

用户在桌面工作台点击折叠按钮后，侧栏缩为图标栏，主内容立即使用释放出的空间；图标仍可导航并能识别其目的。

### 恢复与记忆

用户点击展开按钮恢复完整侧栏。刷新页面后，Cove 恢复该浏览器最近保存的折叠状态。

## 功能需求

- `NAV-FR-001`：桌面侧栏必须提供可访问的折叠与展开控制，并同步调整主内容偏移。
- `NAV-FR-002`：折叠状态必须保留可见导航图标、活动项样式、可访问名称和完整导航能力。
- `NAV-FR-003`：系统必须将折叠偏好保存在浏览器本地；读取或写入失败不得阻断工作台。
- `NAV-FR-004`：移动端必须继续使用现有抽屉菜单，不受桌面折叠偏好影响。

## 非功能需求

- `NAV-NFR-001`：布局必须适配深浅主题、键盘操作以及 reduced-motion 偏好。
- `NAV-NFR-002`：偏好不得包含账号、凭据或其他敏感数据。

## 验收条件

- `NAV-AC-001`：在宽度 1440px 点击“折叠侧栏”，侧栏变窄、内容左移，当前页面和会话状态不丢失；再次点击恢复。
- `NAV-AC-002`：折叠后，可通过鼠标和键盘使用每个可见导航项，控件与链接具有中英文可访问名称。
- `NAV-AC-003`：刷新后恢复最后保存的折叠偏好；模拟 localStorage 不可用时界面仍可切换。
- `NAV-AC-004`：在 375px 和 768px 下继续显示现有菜单按钮与抽屉，不显示桌面折叠控件。

## 开放问题

- 无。用户于 2026-09-19 明确要求增加折叠功能；范围按桌面侧栏、浏览器本地偏好确定。
