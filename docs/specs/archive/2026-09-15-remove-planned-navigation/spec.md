# 移除规划中菜单

## 背景与目标

当前导航将应用、网络、备份、任务、设置显示为不可点击的“规划中”按钮。维护者要求直接移除这些菜单。

## 功能需求

- `NAV-FR-001`：桌面侧栏与移动端菜单必须移除应用、网络、备份、任务、设置五个占位入口，并移除因此变空的系统分组。
- `NAV-FR-002`：必须保留概览、用户、角色、资源和文件入口的现有路由与权限规则。

## 非目标

不实现规划能力，不修改 API、数据模型、权限资源或现有页面内容。

## 验收条件

- `NAV-AC-001`：中英文、深浅主题以及 375/768/1440px 下均不显示上述五项与系统空分组。
- `NAV-AC-002`：现有菜单仍按权限显示，可通过键盘访问并正常导航；移动端选择菜单后正常收起。
- `NAV-AC-003`：Web lint、typecheck、build 与 diff 检查通过。
