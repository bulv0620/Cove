# Cove 品牌统一

## 背景与批准范围

维护者已批准品牌改名，并进一步明确：项目维护的源码、配置、测试和文档（含归档 Spec）全部统一为 Cove，不保留旧名称或迁移兼容逻辑。此次明确指令作为范围修订批准，覆盖此前兼容方案，保持原需求 ID。

Cove 定位为运行在 NAS 上的自托管个人工作台。当前有身份权限基础与 SMB 文件访问；图床、Notes、Applications 和 Tasks 仍为规划。

## 目标与非目标

- 产品与 GitHub 仓库使用 `Cove`；内部工程和部署标识使用 `cove`。
- 项目维护的文本不残留原品牌，归档文档同步规范名称；历史验证日期和结果不变，规范后的命令不冒充原始逐字记录。
- 不迁移浏览器状态，不读取旧环境变量，不识别旧上传临时前缀。
- 不重写 Git 提交历史，不移动本地项目根目录，不修改第三方依赖内部内容。
- 不变更实际数据库、NAS 文件或真实环境凭据；不实施规划功能或生产发布。
